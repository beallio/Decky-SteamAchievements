Achievements Restored Installer

1. Extract this archive directly onto the SteamOS Desktop.
2. Double-click "Install Achievements Restored".
3. Approve the installation and administrator-authentication dialogs.

No Konsole window is required.

The installer downloads the latest stable Achievements Restored release from:
  https://github.com/beallio/Decky-SteamAchievements

The installer log is written to:
  /home/deck/Desktop/Decky Plugin Installer.log
